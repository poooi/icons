POI / REFERENCE STUDY

Aircraft game-art references

26 equipment illustrations mapped to 20 aircraft icon IDs. The accepted generic carrier family (6, 7, 8, 9, 45, 46) is excluded from this study. The SVGs below show the current assets. Icons 56–60 have now been revised against this game artwork; the other entries retain their earlier silhouettes.

Reference priority: current game icon for composition, color and badge; game equipment illustration for unclear structure; historical photographs only as supplementary evidence. Equipment art may show an older badge or a different viewpoint. A category can cover several aircraft designs.

Source images are kcwiki-hosted 390 × 390 equipment cards, displayed at 260 px and linked at their original resolution. “HD” is the source filename, not a claim of unlimited detail. Images load from kcwiki; source links remain available if an image cannot load.

Compare the low-wing twin-float layout of Zuiun with the biplane Type 0 observation seaplane. Keep the shared category silhouette; do not add a second wing to every member.

Icon 21

The Ka-go has a large overhead rotor, a separate forward propeller and fixed landing gear. It is an autogyro, not a generic helicopter.

Icon 22

The Type 3 liaison aircraft has a high wing, forward propeller and exposed fixed landing gear; preserve those distinguishing features.

Icon 33

The Type 2 flying boat has four wing-mounted propeller engines and a boat hull. Its outboard stabilizing floats differ from a twin-float seaplane.

Icon 37

Both representative land attackers have two propeller engines. Match the source icon orientation and reconstruct the nacelles separately from the fuselage.

Icon 38

Raiden is a single-engine tractor-prop fighter. Its short, full fuselage and source viewpoint differ from the approved generic carrier silhouette.

Icon 39

The game jet Keiun has twin jet nacelles and its own wing and tail arrangement. Use this fictional game configuration rather than extrapolating from a historical propeller Keiun.

Icon 40

Kikka has two separate underslung jet nacelles, a conventional tail and comparatively straight wings. The game illustration is the primary layout reference.

Icon 43

Type 2 float fighter and Kyoufuu both show a central main float and smaller stabilizing floats. Keep the source category silhouette and common strut treatment.

Icon 44

Hien and Hayabusa are single-engine army fighters. This category also contains other aircraft types; it must not be treated as a twin-engine-only family.

Icon 47

Tokai has twin propeller engines and broad wings. The perspective and rounded fuselage distinguish it from the land-attacker category silhouette.

Icon 48

Ki-102 has twin propeller engines and a long nose. This archived equipment card shows an older land-fighter badge; use the current atlas assault badge and lettering.

Icon 49

Shinzan has four propeller engines and a long airframe. Engine count and spacing must remain distinct from the twin-engine land attackers.

Icon 50

Night reconnaissance equipment spans different airframes, including the biplane Type 98 and monoplane Type 0. Keep the shared game category symbol instead of imposing one specific aircraft on all variants.

Icon 51

Night Zuiun supplies the wing/float arrangement and night equipment context. Keep the original icon night lettering and light colors; use the illustration to check where structural details belong.

Icon 56

The game Me 262 illustration shows swept wings and two nacelles. Match the icon viewpoint without substituting the Kikka body.

Icon 57

The game propeller Shinden shows canards ahead of the main wing and a rear pusher propeller. Compare directly with equipment 548 before drawing the propulsion variants.

Icon 58

The Type 99 night dive bomber retains a forward propeller and fixed landing gear. Its category icon viewpoint differs from the approved carrier family; preserve that distinction.

Icon 59

The Ho229 game illustration supplies the flying-wing outline, twin intakes and lack of a conventional tail. Use it ahead of the previously examined museum reproduction.

Icon 60

Use the game jet Shinden illustration for the canards, rear main wing, fins and jet installation. It is a game variant; historical J7W photographs cannot establish these jet details.
